# 🌀 TORI — Game / Movie Concept

A mystical journey through ancient torii gates that function as wormholes across space and time.

A boy becomes a warrior to rescue his sister, kidnapped by the Kage-shū (影衆) — a corrupted samurai clan seeking to control the gate network and rewrite history.

## 🎨 Style
Deeply Japanese — Ukiyo-e visuals, Sumi-e wormhole sequences, Wabi-sabi environments, traditional instruments, and the emotional core of Mono no aware.
